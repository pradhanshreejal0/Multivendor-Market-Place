## 🏗️ What Has Been Built

### Phase 1: Foundation & Core Infrastructure
- **Monorepo setup:** Turborepo root workspace (`packages/client`, `packages/server`, `packages/shared`).
- **Shared Package (`@marketplace/shared`):** Role constants (`customer`, `vendor`, `admin`) and Zod authentication validation schemas.
- **Backend Core:** Express server with helmet, cors, morgan, custom error classes, global error handler, and MongoDB connection via Mongoose.
- **Authentication & RBAC:** User model (bcrypt salt rounds 12), JWT access/refresh token flow, registration/login/refresh endpoints, and strict RBAC middleware.
- **Frontend Scaffolding:** Vite + React (JSX) with Tailwind CSS, Axios client with auto-refresh interceptors, and i18next configured for English (`en`) and Nepali (`ne`) bilingual support under the brand **ZenithBazaar**.
- **Layout & Routing:** StorefrontLayout, VendorLayout, AdminLayout, ProtectedRoute guards, and React Router v6 setup.

### Phase 2: Product Catalog, Categories & Search
- **Categories:** Hierarchical category Mongoose model, tree builder service, public listing, and admin CRUD routes.
- **Products Backend:** Bilingual product schema (`en`, `ne`), variants, stock levels, moderation status (`pending`, `approved`, `rejected`), pagination, multi-criteria filtering, full-text search indexes, and ReDoS regex protection.
- **Vendor Product UI:** Product listing dashboard and creation/editing form with variants builder.
- **Storefront Catalog & Search UI:** Product catalog grid, category sidebar filter, price range slider, sorting, product detail view with image gallery & variant selector, and search bar with autocomplete.

### Phase 3: Cart, Checkout & Payments
- **Cart Module:** MongoDB-backed persistent user cart with quantity adjustments and stock validation.
- **Checkout & Order Splitting:** Multi-vendor order splitting backend, atomic stock deductions (`findOneAndUpdate` to prevent overselling race conditions), checkout summary, and shipping fee calculation (NPR 150/vendor).
- **Payment Gateways:** Integration abstraction for **eSewa**, **Khalti**, **FonePay**, **Bank Transfer** (with receipt upload & admin confirmation), and **Cash on Delivery (COD)**, with secure payment verification authorization checks.
